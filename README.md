# AI相場診断

GitHubだけで動く、株価・為替の情報サイトです。

| タブ | 内容 | 更新 |
|---|---|---|
| 予想 | ドル円・日経平均・S&P500・NASDAQの「明日・1ヶ月後・3ヶ月後」の上昇／下落予想、予想レンジ、過去の的中率 | 自動（平日17時） |
| 注目株 | ウォッチリスト（話題の銘柄）と出来高急増銘柄の3期間予想 | 自動（平日17時） |
| 値上がり | 日本株45銘柄・米国株42銘柄の値上がり・値下がりランキング（前日比・年初来・1年間） | 自動（平日17時） |
| 割安株 | 日本株・米国株のPER・PBRによる割安株ランキング（総合・PER・PBR・配当で並べ替え） | 自動（平日17時） |
| 優待 | 株主優待ランキング（優待利回り順） | 優待内容は手入力、株価は自動 |
| AI診断 | 日本株・米国株の個別銘柄の「明日・1ヶ月後・3ヶ月後」予想 | 自動（平日17時） |
| 掲示板 | 誰でも書き込める掲示板（アカウント不要） | リアルタイム |

## ファイル構成

- `index.html` … サイト本体（スマホ対応）
- `build_data.py` … データ取得と計算（毎日自動実行）
- `.github/workflows/update.yml` … 自動実行の設定
- `firebase-config.js` … 掲示板の設定（自分で貼り付け）
- `firestore.rules` … 掲示板のセキュリティルール
- `data/yutai.json` … 株主優待の内容（自分で入力）
- `data/` のその他のファイル … 自動で作られる計算結果（最初はサンプル値）

## 1. サイトの公開（GitHub）

1. GitHubで新しいリポジトリを **Public** で作成
2. このフォルダの中身をすべてアップロード
   （`.github` フォルダは隠しフォルダなので、忘れずに含める）
3. **Settings → Pages** で Source を「Deploy from a branch」、
   Branch を `main` / `(root)` にして保存
4. **Actions** タブ →「予想データ更新」→「Run workflow」で一度手動実行
5. 数分後、`https://ユーザー名.github.io/リポジトリ名/` で表示されます

以降は平日17時ごろに自動更新されます。

## 2. 掲示板の設定（Firebase・無料）

掲示板を使わない間は「準備中」と表示されるだけで、他の機能は動きます。

1. https://console.firebase.google.com/ でプロジェクトを作成
   （Googleアナリティクスはオフで構いません）
2. **ウェブアプリを追加**（`</>` のアイコン）→ 表示される `firebaseConfig` の
   中身をコピーし、`firebase-config.js` の `null` の部分と置き換える
3. **Authentication** →「始める」→ ログイン方法で **匿名** を有効にする
4. **Firestore Database** →「データベースを作成」→ 本番環境モード、
   ロケーションは `asia-northeast1`（東京）
5. Firestore の **ルール** タブに `firestore.rules` の中身を貼り付けて「公開」
6. 書き換えた `firebase-config.js` をGitHubにアップロード

※ `firebaseConfig` の値は公開されても問題ない設計です（書き込み制限はルール側で行います）。
※ うまく書き込めない場合は、Authentication → 設定 → 承認済みドメイン に
`ユーザー名.github.io` を追加してください。

### 書き込みの削除

Firebase の Firestore Database → `posts` → 該当の書き込みを選んで削除します。
利用ルールに反する書き込みは早めに削除してください。

## 3. 株主優待の登録

`data/yutai.json` を編集します。株価と利回りは毎日自動で計算されます。

```json
[
  {
    "code": "1234",
    "name": "会社名",
    "shares": 100,
    "value_yen": 3000,
    "content": "自社製品詰め合わせ（3,000円相当）",
    "month": "3月・9月"
  }
]
```

- `shares` … 優待をもらうのに必要な株数
- `value_yen` … 優待1年分を金額に換算した目安（円）
- 内容は各社の公式サイトで確認してから入力してください

## 注目株（ウォッチリスト）の登録

`data/watchlist.json` を編集します。

```json
[
  {"ticker": "285A.T", "name": "キオクシアHD"},
  {"ticker": "PLTR", "name": "パランティア"}
]
```

- 日本株は「証券コード.T」（英字入りのコードもそのまま、例 `285A.T`）
- 米国株はティッカーそのまま

## 銘柄を変えたいとき

`build_data.py` の上の方にある次の部分を編集します。

- `FORECAST_TARGETS` … 予想タブ
- `DIAG_TARGETS` … AI診断タブ（`jp` が日本株、`us` が米国株）
- `JP_STOCKS` / `US_STOCKS` … 値上がり・割安株ランキング

- 日本株は「証券コード.T」（例 `7974.T`）
- 米国株はそのまま（例 `AAPL`）
- 為替は「通貨ペア=X」（例 `GBPJPY=X`、ドル円だけ `JPY=X`）

## 注意

- データ取得に使っている yfinance は非公式ライブラリです。
  Yahoo側の仕様変更で一時的に取得できなくなることがあります。
- 予想は過去の値動きによる機械的なもので、将来を保証するものではありません。
- 掲示板の運営者として、問題のある書き込みは削除できる状態を保ってください。
